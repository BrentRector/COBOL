## Measured
```cobol
       IDENTIFICATION DIVISION.
       PROGRAM-ID. B24SD.
       ENVIRONMENT DIVISION.

       FILE-CONTROL.
           SELECT S ASSIGN TO "b24.tmp".

       01 SR.
          05 SK PIC X DYNAMIC LENGTH.
       FD I.
       01 IR PIC X(5).

       01 OR1 PIC X(5).

           SORT S ON ASCENDING KEY SK USING I GIVING O
```

→ `error COBOLNET1757: SORT/MERGE key 'SK' has no character image`. Rejected — but by a capability message.

## The rule
`cite.py --check 14.9.40.3 "A key data item shall not be a variable-length group, an occurs-depending-on data item, a dynamic-length elementary item or an item subordinate to a dynamic-capacity table"` → `OK §14.9.40.3 6) d)`. SR-14.9.40.3-6 has no verdict.

## What the fixer owes
Screen all four d) arms by name in `SortBinder.SortAddFileKeys` (and the MERGE twin §14.9.24.3) before the image
check, so the capability message never speaks for a rule; negative golden per arm; verdict the row.
